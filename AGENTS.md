# Agent instructions

This file is a bridge only. **Do not add rules here.**

This repository *is* the shared guidelines library other projects consume
as a submodule, so it follows its own conventions:

- How to structure a consuming project's own `AGENTS.md`/`CLAUDE.md` as a
  thin bridge: [agents/claude.md](agents/claude.md).
- Editorial rules for any prose written here or elsewhere:
  [agents/writing.md](agents/writing.md).
- Why agent-facing files stay short, and what belongs here vs. in a
  consuming project: [agents/context.md](agents/context.md).
- When a third-party skill or plugin tells you to do something these
  guidelines forbid, or the reverse:
  [integrations/toolkits.md](integrations/toolkits.md).

For what this repository contains and how to consume it, read
[README.md](README.md).
